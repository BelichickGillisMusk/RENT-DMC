# UNDEFEATED Solar

This folder is the solar work. It is not part of rent-ruby.com.

`npm run build` copies only `site/` to `dist/`. Nothing in this folder is published to the Ruby Street site. A search of `site/` and `src/` found no solar pages, copy, or assets.

The public solar site stays at [undefeatedsolar.com](https://undefeatedsolar.com).
